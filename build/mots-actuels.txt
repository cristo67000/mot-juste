# Les mots actuels : argot, langue des réseaux, vocabulaire récent.
#
# Ni Lexique (des films et des livres d'avant 2010) ni Grammalecte ne les
# connaissent tous : « poucave », « cringe », « banger », « seum » restaient
# dehors. Cette liste leur ouvre une cinquième voie, « actuel » (voir
# construire.py). Un mot n'entre que si le Wiktionnaire le décrit — rien
# n'est rédigé ici, seulement choisi ; les absents sont nommés dans
# build/rapport.txt.
#
# Une vedette par ligne, telle que le Wiktionnaire l'écrit ; une expression
# entre comme un mot. Ce qui suit « # » est un commentaire.
#
# Choisis en novembre 2026, d'après les nouveautés du Petit Robert et du
# Petit Larousse 2026 et 2027 (crush, prompter, polycrise, trumpisme…) et
# les relevés d'argot des 18-24 ans (seum, charo, tarpin, charbonner…).
# Sont laissés de côté les mots que le Wiktionnaire ne décrit que dans un
# autre sens (« flexer » : poser du flex thermocollant), et les insultes
# qui ne sont que cela.
